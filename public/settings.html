Email delivery note

Daily alert emails are sent automatically based on the schedule set in your server's .env file (ALERT_CRON, default 8:00 AM). This page controls who gets alerted and how many days a component can be out before it counts as overdue. Pickup receipts (with the signature attached as a PDF) go out immediately the moment a vendor signs components out — to the same recipient list above. SMTP (email sending) credentials themselves are configured by whoever set up the server, in the .env file — not here, for security.
